Accepted local SQLite migration design: input connection has people(id INTEGER PRIMARY KEY, name TEXT NOT NULL). Add normalized_name TEXT if absent. migrate(connection, fail_after=None) backfills only NULL normalized_name rows using name.strip().lower(), committing each processed row; fail_after raises RuntimeError after that many rows are committed. Repeated runs are safe; old id/name rows must remain untouched. On full completion verify no NULL values before return. Retry after partial failure resumes remaining rows; no destructive cleanup, production operations, or external access. Tests use temporary SQLite fixture only.
