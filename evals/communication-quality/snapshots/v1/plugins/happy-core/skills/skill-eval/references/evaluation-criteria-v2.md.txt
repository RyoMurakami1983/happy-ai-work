# 評価基準2.0.0の移行判断

対象: Refs #45。Constitution 1.0.0、upstream判断プロファイル1.0.0は変更しない。

旧基準1.0.0のcoverage・waste・riskでは伝達の不足や時点を個別に補完していた。2.0.0ではcommunicationをresponse quality内に明示し、安全・正確さ・依頼達成を満たす候補の改善・採用判断で、判断・行動の支障を先に解消する。これは採否に影響する基準変更であり、補助観測として扱わない。

vNext案と旧基準の影響比較: 必要十分な説明は両版で維持する。重要条件欠落・遅い通知は新版で伝達の支障と区別する。無関係な水増しは改善余地とし、詳しい説明が目的の場合は削らない。既存項目との重複減点や、非安全な省略の一律Critical化はしない。過去評価を再採点・上書きせず、新基準のrunは別recordにする。

所有者はIssue #45の新軸と優先度、および1→2→3の実装・検証を会話で明示承認した（2026-09-30、委譲時に承認範囲を再確認）。承認根拠: 「では１，２，３との順序で実装・検証まで進めて、PRを作ったら報告してください。マージは待ってね。」この承認はここに記す新軸・優先度を対象とし、Constitutionの原則順位の変更を含まない。旧版を保存したうえで2.0.0を実装し、draft PRで差分と観測限界をレビュー可能にする。

反例: 短いが費用を欠く回答を採らない。長くても依頼に必要な学習説明は保持する。安全違反はcommunicationの良さで相殺しない。Yohakuの使用・不使用を有効性の証明にしない。
