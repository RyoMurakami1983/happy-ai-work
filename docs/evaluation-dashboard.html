この画面の読み方

品質・安全 → 負担 → 補助スコア

合格完了率とhard failを先に確認。Sが上がっても不合格を相殺できません。Qは採点済み全case、Bは観測済みcase、Sは適格caseが対象です。それぞれの分母を併記しています。

S = Q / (1 + λB)。係数と尺度は取込methodから読みます。draftや証拠不足はS対象外。推定Bに基づくSは推定負担の補助値です。

cohortを混ぜない

モデル、snapshot、effort、tools、権限、実行上限、fixture、method、dataset、case構成、harness、source、負担の測定方法が違う記録は別cohortです。欠測点や欠けた反復を線で飛び越しません。

条件ごとにQ尺度・B単位も確認してください。混在選択に合算した平均・合格率・改善率は出しません。実装revisionだけの変化は観測対象として保持します。

負担の意味と境界

回避可能な割込みの寄与は b × (1 + βd²)。必要な質問を回避可能に先送りした分は b × βd²。適切な必要承認・停止は0ペナルティです。

dは合理的に認識できた時点から進めた、その判断に依存する作業量。返信待ち時間や単なる経過時間ではありません。素の負担・遅延・手戻り・人の確認時間は別表示し、Bへ二重加算しません。

読込みと保存の境界

ファイル選択で全入力を検証後、現在の表示データを置換します。不正なJSONは前データを保持して拒否します。データはこのページのメモリ内だけに残り、ページの再読込みまたは「データを消去」で消えます。

公開repoには架空fixtureと契約のみを保存します。raw trace、会話、private rubric、個人情報、認証情報は取り込まず、sanitize済みの要約とopaqueな証拠ID/hashを使用してください。機械検証だけでsanitizationを保証できません。

CLI検証: python scripts/evaluation_dashboard.py INPUT.json。全判定が揃っていない記録も分母に残します。Aは通常評価、Bは判定不能、Cは緊急例外で、B/Cを通常PASSへ読み替えません。
