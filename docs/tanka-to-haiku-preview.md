## 基本確認

以下の架空依頼について、実装者が指示を手動でたどり、適用範囲と矛盾を点検した。独立した生成・採点や自動選択の実測ではない。

| 模擬依頼 | 手動確認した対応 |
| --- | --- |
| 条件を含む引継ぎ文を研ぐ | 「事実・必要な意味を保つ」という境界を確認 |
| 改善前後の変化を残して報告を研ぐ | 「移ろいまで要るなら短歌のように」という選択を確認 |
| コードの意味を研ぐ | 名前と処理を照らし合わせ、振る舞いを保つという指示を確認 |
| 設計案の目的と関係を研ぐ | 目的と関係を照らし合わせ、組み直すという指示を確認 |

形式確認はrepo標準の品質検証と、frontmatter・UI metadataのfocused checkで行う。`.agents/skills`はこのcheckoutにもworkspace直下にも存在せず、ローカル登録やPC適用は行わない。

## 試用で観察すること

文章・コード・設計のそれぞれで、核と関係が伝わるかを確認する。事実の追加、意味や振る舞いの変化も残す。文字数・行数は補助指標とし、短くなったことだけで成功としない。

独立した振る舞いの比較、自動選択、実利用での有用性は未検証。比較するときは条件と判定基準を先に固定し、生成と採点を分離する。今回skill-evalの変更や新たな比較実験は行わない。
