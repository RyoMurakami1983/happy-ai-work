# Archived implementation-plan

This is the immutable source from happy-ai-work commit `42f71ff` before planning was integrated into `implement`. The former entrypoint is named `SKILL.md.txt` so this directory is not a discoverable skill. It is outside every plugin distribution root.

`snapshot.json` records hashes of the original files (with only the entrypoint filename changed). Historical instructions and relative links retain their original meaning and are not current invocation instructions. Use `plugins/happy-coding/skills/implement/` for maintained planning resources and rendering tools. Existing user plans are still supported; do not reinstall this archive to resume one.
