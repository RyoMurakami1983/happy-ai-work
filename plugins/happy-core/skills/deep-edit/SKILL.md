# Deep Edit

## 編集順序

1. 読者と目的に対して中心主張が明確か確認する。
2. 重複、飛躍、順序の問題を直し、各節の役割を一つにする。
3. 根拠と断定の強さを合わせ、未確認事実を識別する。
4. 長文、曖昧語、名詞過多、受け身、不要な修飾を整える。
5. 表記、句読点、見出し、リンクを校正する。

著者固有の声を均一なAI文体で消さない。意味を変える大きな編集は理由を示し、原文と区別できる形で提案する。最終稿に加えて、主要変更点と確認が必要な事実を短く返す。
