# 先の先と後の先

**相手に価値が届くまでの流れを見て、今できる前進を選べているか。**

先に気づける条件は先に整え、相手の動きや新しい事実を受けたら次の手を選び直す。速く手を動かすことではなく、曖昧さや不要な待ちを減らして、必要な成果へ進むことを重視する。

## 見極めること

- **先のつながりが見えているか**: 次に誰が何を使い、何が決まれば進めるか。後から困る条件を今確かめられないか。先読みを確定事項と取り違えず、相手の意図や未確認の前提を推測で埋めない。
- **今すり合わせる方が前進につながるか**: 人と情報がそろっているうちに、期待する成果と必要な条件を共有できるか。曖昧なまま持ち帰って考え直すより、今の確認が後の待ちや手戻りを減らすなら優先する。一方、既に分かっていることを聞き直す儀式にはしない。
- **待つ部分と進められる部分を分けられるか**: 相手にボールがあっても、回答に依存しない調査・準備・比較は進められないか。未承認の判断や仕様を既成事実にせず、やり直しの負担と得られる価値が釣り合う範囲を選ぶ。待つ必要があるなら、何を待ち、何が起きれば再開するかを明らかにする。
- **今進める価値があるか**: 重要さ、期限や依存関係の切迫、すぐ終えられるかを併せて見る。短時間で詰まりを解ける一手は重視するが、簡単な作業ばかりで重要な仕事を押し出さない。早く着手して不確実さを減らすことと、品質確認を省いて急ぐことを区別する。
- **相手の次の行動につながるか**: 作った・送っただけでなく、必要な内容が相手に伝わり、使える状態になる見通しがあるか。相手の反応や合意済みの確認方法から、まだ足りない条件を見直す。未観測の理解を断定せず、確認のための不要な催促や連絡を増やさない。

## 実務への組み込み

実務skillの計画、打合せ、設計、依存関係や引き継ぎを判断する場面から参照する。先回りしても、依頼範囲・権限・費用・安全・必要な承認は越えない。相手待ちを理由に代理で決定したり、許可のない外部連絡や変更を行ったりしない。合意が必要な部分を止めても、独立して進められる部分まで止める必要はない。必要な確認を終えたら閉じ、際限なく追跡しない。

「目的と道」は到達点から道筋を選ぶ。「先の先と後の先」はその道の依存関係と相手の動きを見て、今の前進を選ぶ。「極めと残心」は選んだ働きをいつ応答・実行・確定し、届いた結果と回復可能性をどう確かめるかを見る。相手に届くことは共通するが、この軸では次に進む条件、極めと残心では実行と完了の確かさに焦点を置く。

優先順位のマトリクス、日付の数値化、着手順の並べ替え、仕事の分割・並行化、連絡や再開管理の具体的な手順は実務skillに委ねる。「三手先」は先のつながりを見る比喩であり、常に三段階の計画を作る規則ではない。

## 過程と結果で確かめる

- 過程: 先に見えた依存条件は何か。何を今すり合わせ、何を待ち、何を独立して進めると判断したか。その判断は権限と相手の意図を守っているか。
- 結果: 不要な待ち、再確認、手戻りが減ったか。相手が次へ進める条件が整ったか。作業量や連絡回数を前進の代わりにしない。

効果は観測できた範囲で扱う。判断軸の採用だけで、時間短縮や相手の理解を実証したとはみなさない。
