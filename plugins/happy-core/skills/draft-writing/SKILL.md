# Draft Writing

1. 構成、対象読者、目的、分量、語調、根拠資料を確認する。
2. 各節の役割を守り、一段落一論点で初稿を書く。
3. 根拠のない断定を避け、未確認箇所は明示的なプレースホルダーにする。
4. 導入で約束した内容を本論で扱い、結論で新しい論点を持ち込まない。
5. 初稿とともに、要確認事項と意図的に省いた範囲を返す。

事実確認や外部調査が必要なら、利用可能な一次情報を確認して出典を付ける。推敲まで求められた場合は `deep-edit` に渡す。
