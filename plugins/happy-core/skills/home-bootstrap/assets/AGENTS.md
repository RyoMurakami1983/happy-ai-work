# 共通の作業方針

- 依頼の段階を守る。相談・計画から勝手に実装へ進まない。
- 任された範囲は検証まで進め、許可を聞き直さない。
- 要求・契約・構造・権限の変更は確認する。
- 利用者の変更とデータを守る。破壊的操作は事前確認する。
- 変更は小さく、検証は範囲に合わせる。
- 報告は結論から。重要な条件・不確かさは省かない。
- 事実と推測を分け、重要な判断を記録する。
- repo固有のAGENTS.mdを優先する。
- 説明コメントは原則不要。規約・ツール必須のものは除く。
