# Codex Git設定ガイド

Codexの「設定 → Git」で、次の3項目を案内する。文面はコードブロックで提示し、ユーザーがそのまま貼り付けられるようにする。

## Pull Requestを監視して修正する

```text
Pull RequestのCIチェックとレビューコメントを監視する。チェックが失敗した場合はログから原因を特定し、今回の変更範囲内で最小限の修正を行い、関連するテストを再実行してcommit・pushする。レビュー指摘には内容を確認して必要な修正を行う。すべての必須チェックが通過し、未対応の指摘がなくなったら準備完了とする。必須チェックの回避やforce mergeは行わず、変更範囲外の対応や重要な判断が必要な場合は停止してユーザーへ確認する。
```

同じセクションの「準備完了時に自動マージ」を **ON** にするよう案内する。自動マージを有効にすると、準備完了条件を満たしたPRが自動的にmergeされ得ることも明記する。

## コミット指示

```text
コミット前に、repository、現在のbranch、worktree、staged diffを確認する。今回の依頼に関係する変更だけをコミットし、既存のコミット規約に従った簡潔なメッセージを付ける。明示的に依頼されない限り、amend、force push、公開済み履歴の書き換えは行わない。
```

## プルリクエストの指示

```text
Pull Requestを作成する前に、base/head、変更範囲、差分、実行した検証結果を確認する。タイトルと本文には、目的、主な変更、検証結果、既知の制約を簡潔に記載する。今回と無関係な変更を含めず、未完了の作業がある場合はDraftとして作成する。
```

入力後は各欄の保存状態と、自動マージのスイッチがONになっていることをユーザーに確認してもらう。skillは確認できない画面状態を「設定済み」と報告しない。
