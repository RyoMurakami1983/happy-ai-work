# Writing Plan

読者が読み終えた後に理解・判断・行動できることを成功条件として、文章の設計図を作る。

1. 読者、目的、媒体、分量、締切、語調、根拠資料を確認する。
2. 主張と根拠、読者が持つ疑問、対象外を分ける。不足情報を創作しない。
3. 導入、本論、結論の流れを作り、各節に「この節で伝える一文」を置く。
4. 引用・数値・固有名詞など検証が必要な箇所を明示する。
5. タイトル候補、構成、必要資料、未確定事項をhandoffする。

ユーザーがそのまま下書きまで求めた場合は、構成の合意後に `draft-writing` へ進む。
