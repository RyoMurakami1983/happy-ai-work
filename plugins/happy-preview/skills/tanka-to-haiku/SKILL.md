# 短歌と俳句

小さな形に、大きな意味を宿す。
よく見て、核をつかむ。
言葉を選び、取り合わせ、説明に頼らず意味を立ち上げる。
一景で届くなら俳句のように。移ろいまで要るなら短歌のように。
削るだけでなく、組み直す。薄めず、研ぐ。
定型や飾りを目的にせず、その仕事にふさわしい形を選ぶ。

文章では言葉と具体、コードでは名前と処理、設計では目的と関係を照らし合わせ、選び直し、組み直す。

事実・必要な意味・振る舞いを保ち、依頼範囲と指定形式を守る。詩型は強制しない。
