# Deep Review

固定された agent ファイルには依存しない。subagent が利用可能なら、差分と最小限の要件だけを渡して独立レビューを依頼する。利用できない場合は、新しいレビュー観点でローカル差分を読み直す。Copilot CLI はユーザーが明示した場合だけ実験的な追加レビュアーとして使い、その結果も必ずコードとテストで再検証する。

## レビュー手順

1. 対象diff、要件、テスト結果、repo instructionsを確認する。
2. 正しさ、回帰、データ損失、権限・機密境界、並行性、エラー処理、テスト妥当性を変更内容に応じて調べる。
3. 指摘候補ごとに、該当行、発生条件、観測される影響を確認する。再現または論理的証明が弱い指摘は除外する。
4. 指摘を重大度順に返す。各指摘には、場所、問題、発生条件、最小修正方針を含める。
5. 指摘がなければ「重大な指摘なし」とし、確認した範囲と残存リスクを短く述べる。

レビュー中に修正は始めない。ユーザーが修正まで求めた場合のみ、指摘確定後に別工程として実装する。スタイル上の好みだけを不具合として報告しない。
